# net_tran_helper

基于 Qt 的网络调试助手，支持 TCP 客户端、TCP 服务端、UDP 客户端和 UDP 服务端。

## 功能

- 十六进制与 ASCII 数据收发
- 定时自动发送
- 多客户端连接和群发
- 保存并恢复界面配置
- UDP 客户端与服务端分别统计累计收发字节数，支持独立清零

UDP 统计按实际数据字节数累计，不受十六进制/ASCII 显示、暂停显示或清空日志影响。
服务端群发按每个目标成功发送的字节数累加；发送失败不计入统计。
点击“统计清零”或重新启动程序后，统计从零开始。

## 构建

使用 Qt Creator 打开 `nettool.pro`，选择已安装的 Qt 桌面套件进行构建。
项目使用 Qt Core、Gui、Network 和 Widgets 模块。

本仓库不包含本地设备协议示例数据。原始说明暂保留在本地。

## 测试

使用 Qt Creator 打开 `tests/udp_byte_counts.pro`，构建并运行 Qt Test 测试程序。
测试使用本机回环 UDP，覆盖客户端/服务端收发计数、失败发送、显示切换、统计清零和群发。
