# net_tran_helper

基于 Qt 的通信调试助手，支持 TCP 客户端、TCP 服务端、UDP 客户端、UDP 服务端和串口收发。

## 功能

- 十六进制与 ASCII 数据收发
- 定时自动发送
- 多客户端连接和群发
- 保存并恢复界面配置
- UDP 客户端与服务端分别统计累计收发字节数，支持独立清零
- 串口选择/刷新，支持自定义波特率、数据位、校验位、停止位和流控
- 串口十六进制/文本/ASCII 收发、定时发送、日志保存、暂停显示和独立字节统计

UDP 统计按实际数据字节数累计，不受十六进制/ASCII 显示、暂停显示或清空日志影响。
服务端群发按每个目标成功发送的字节数累加；发送失败不计入统计。
点击“统计清零”或重新启动程序后，统计从零开始。

## 串口（RS422 / RS485）

连接对应串口适配器并安装驱动后，在“串口”页选择 COM 口，设置与板卡一致的参数，
点击“打开串口”即可收发原始数据。RS422/RS485 电气接口由适配器提供，
RS485 半双工收发方向需要适配器或驱动自动控制；当前不提供手动 RTS 方向切换。
默认参数为 115200、8 数据位、无校验、1 停止位、无流控，可按板卡修改。

串口是字节流，一次接收事件可能只有半帧，也可能包含多帧；本模块不做协议解析、
分帧或校验和处理。十六进制适合发送任意二进制数据，文本沿用现有页面的 Latin-1 编码，
ASCII 模式沿用现有转义规则。十六进制选项优先于 ASCII 模式。
串口参数和显示/定时选项自动保存，启动时不会自动打开设备。
定时发送仅在串口打开时运行，关闭或严重设备错误会停止发送。

日志中的“发送提交”表示数据进入发送队列；发送统计按 `bytesWritten` 通知累计，
不表示板卡已确认收到。清空日志和暂停显示不影响统计。待发送队列超过 1 MiB 时停止定时发送。

## 构建

使用 Qt Creator 打开 `nettool.pro`，选择已安装的 Qt 桌面套件进行构建。
项目使用 Qt 5（建议 5.12 或更高版本）的 Core、Gui、Network、Widgets 和 SerialPort 模块。
部署时需同时提供对应版本的 Qt SerialPort 运行库（Windows 为 `Qt5SerialPort.dll`）。

本仓库不包含本地设备协议示例数据。原始说明暂保留在本地。

## 测试

使用 Qt Creator 打开 `tests/udp_byte_counts.pro`，构建并运行 Qt Test 测试程序。
测试使用本机回环 UDP，覆盖客户端/服务端收发计数、失败发送、显示切换、统计清零和群发。

`tests/serial_module.pro` 验证串口配置恢复、未打开时的发送限制、无效参数和打开失败状态。
该测试无需板卡；实际收发、拔插和 RS485 方向控制需要连接真实适配器与板卡验证。
